# RetailIQ – End-to-End Data Engineering Pipeline

RetailIQ is an end-to-end data engineering project built using a real-world e-commerce dataset.

The project demonstrates:

- ETL Pipeline
- Data Cleaning
- Data Warehousing
- SQL Analytics
- Power BI Dashboard
- Automated Reporting

## Tech Stack

- Python
- Pandas
- NumPy
- MySQL
- SQLAlchemy
- Power BI
- Git & GitHub
